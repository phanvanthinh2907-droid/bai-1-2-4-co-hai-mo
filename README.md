# Bài 1.2.4 - Định dạng tổng hợp (Cô hái mơ)

Bài tập chương 1 - HTML, sách *Bài tập Thiết kế Web* (NXB ĐHSP TP.HCM, 2023), học phần COMP1802.

Sinh viên thực hiện: Phan Văn Thịnh

Trong sách, trang này tên là `co-hai-mo.html`; ở đây đặt tên `index.html` để GitHub Pages tự mở.

## Kiến thức sử dụng
- Tiêu đề trang (title), tiêu đề h1 canh giữa align="center"
- Định dạng ký tự: b (đậm), i (nghiêng), u (gạch chân), s (gạch ngang)
- Thẻ pre giữ nguyên xuống dòng, không rớt dòng khi thu nhỏ cửa sổ
- Đường kẻ ngang hr, chú thích small, ký tự đặc biệt `&lt;` `&gt;`

## Cách chạy
Mở thư mục bằng VS Code, chuột phải `index.html` → **Open with Live Server**.
